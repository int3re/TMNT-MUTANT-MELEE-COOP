# meleenet — documentation

**English** · [Русский](../README.md)

meleenet is a network-play mod for the PC game *TMNT Mutant Melee*: up to four players, each with a copy of
the game of their own. It is made for the game's Russian release. The short story is on the
[front page](../../README.en.md); these pages are the long one.

| [The launcher](LAUNCHER.md) | every screen and tab, updates, a proxy for GitHub, the command line |

The mod and the launcher speak Russian. Names of buttons and menu items are given as they are on the
screen, with a translation in brackets where it helps.
