# Настройки

[Документация](README.md) · [Установка](INSTALL.md) · [Лаунчер](LAUNCHER.md) · [Сетевая игра](NETPLAY.md) ·
[Управление](CONTROLS.md) · **Настройки** · [Если что-то не так](TROUBLESHOOTING.md)

**Русский** · [English](en/SETTINGS.md)

Настройки хранятся в трёх местах:

| Где | Что | Кто это меняет |
|---|---|---|
| `meleenet.ini` рядом с `ztmnt.exe` | настройки самого мода: окно, картинка, сетевая игра, мышь | вкладки лаунчера ГРАФИКА и СЕТЬ или текстовый редактор |
| `tmntwire.hks` рядом с `ztmnt.exe` | файл привязок самой игры: клавиши | вкладка лаунчера УПРАВЛЕНИЕ |
| `%APPDATA%\meleenet\launcher.ini` | настройки самого лаунчера | вкладка лаунчера ЛАУНЧЕР |

Игра читает всё **при запуске**: изменение, сделанное при запущенной игре, подействует в следующий раз.

## Строки лаунчера и что они записывают

### ГРАФИКА

| Строка | Значения | `meleenet.ini`, `[video]` |
|---|---|---|
| **Окно игры** | На весь монитор · В окне | `mode = borderless \| window` |
| **Разрешение** | Как монитор · режимы монитора | `resolution = auto \| 1920x1080` |
| **Формат кадра** | Под монитор · 4:3 с полосами | `aspect = wide \| 4:3` |
| **Меню** | На весь кадр · 4:3 с полосами | `menus = wide \| bars` |
| **Сглаживание** | Выкл · 2x · 4x · 8x | `antialiasing = 0 \| 2 \| 4 \| 8` |
| **Фильтр текстур** | Выкл · 4x · 8x · 16x | `anisotropy = 0 \| 4 \| 8 \| 16` |
| **Контуры героев** | Рисованные · Выкл | `toon_shading = 1 \| 0` |
| **Тени** | Живые · Простые | `shadows = 1 \| 0` |
| **Частицы** | Все · Меньше · Мало | `particles = 100 \| 70 \| 40` |

Строка, которая сейчас ни на что не влияет, показана бледной: **Меню** — при формате кадра «4:3 с полосами»
(у такого кадра нет боков, которые меню могли бы занять) и при установленном моде старше 0.1.1.

### СЕТЬ

| Строка | Значения | `meleenet.ini` |
|---|---|---|
| **Задержка ввода** | 1 – 6 кадров | `[net] delay = 1 … 6` |
| **Видят в Steam** | Друзья · Все | `[net] lobby = friends \| public` |
| **Кнопки мыши в игре** | Работают · Выкл | `[input] mouse = 1 \| 0` |

### УПРАВЛЕНИЕ

Клавиши и кнопки мыши: см. [Управление](CONTROLS.md).

## `meleenet.ini`

Строка, начинающаяся с `;`, — пояснение (в файле они на английском). Если ключа в файле нет, берётся его
значение по умолчанию; если нет самого файла — все значения по умолчанию. При обновлении мода лаунчер
оставляет ваш `meleenet.ini` как есть.

### `[video]`

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `mode` | `borderless` | `borderless` — окно без рамки на весь монитор: разрешение рабочего стола не меняется, Alt+Tab работает сразу. `window` — обычное окно. `game` — как в оригинале: эксклюзивный полный экран 640×480; экран мод тогда не трогает |
| `resolution` | `auto` | размер кадра, который рисует игра: `auto` — как у монитора (без рамки) или три четверти высоты рабочего стола (в окне); `1280x720` — свой размер, не меньше 320x240 |
| `aspect` | `wide` | `wide` — кадр по форме монитора (16:9, 16:10, 21:9), в боях обзор шире по бокам. `4:3` — картинка как в оригинале, с чёрными полями по бокам |
| `menus` | `wide` | `wide` — меню занимают весь широкий кадр: фоны, трубы и стены идут до краёв экрана; `bars` — меню 4:3 с чёрными полосами по бокам |
| `window_width`, `window_height` | `0` | размер окна для `mode = window`; `0` — по размеру кадра |
| `antialiasing` | `4` | сглаживание краёв (MSAA): `0`, `2`, `4`, `8`. Работает в `borderless` и `window`, когда кадр занимает всё окно; если видеокарта столько не умеет, берётся меньше |
| `anisotropy` | `16` | анизотропная фильтрация (чёткость текстур под углом): `0` — выключена, `2`, `4`, `8`, `16`; не больше, чем умеет видеокарта |
| `toon_shading` | `1` | контуры героев: `1` — рисованные, `0` — выключены |
| `shadows` | `1` | `1` — живые тени, `0` — простые |
| `particles` | `100` | сколько частиц рисуется, в процентах: `0` … `100`. В сетевой игре — всегда `100` |

`toon_shading`, `shadows` и `particles` — настройки картинки самой игры; она хранит их и в своём `tmnt.ini`.
Значение из `meleenet.ini` главнее; если ключа в `meleenet.ini` нет, решает `tmnt.ini`.

В версии 0.1.0 в файле по умолчанию стояло `menus = bars`: широкие меню тогда ещё не были готовы. При
обновлении до 0.1.1 лаунчер один раз меняет эту строку на `menus = wide`; дальше она ваша.

### `[input]`

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `mouse` | `1` | `1` — кнопки мыши можно назначать действиям, как клавиши ([Управление](CONTROLS.md)); `0` — кнопки мыши в игре не работают |
| `keys_own` | — | сюда лаунчер записывает вашу собственную раскладку клавиш, пока выбрана готовая; мод этот ключ не читает |

### `[net]`

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `name` | `player` | ваше имя на странице СЕТЕВАЯ ИГРА, латиницей; пока стоит `player`, имя берётся из Steam, если он подключён |
| `port` | `47830` | порт UDP, на котором хост ждёт гостей, подключающихся по адресу. Если у хоста порт другой, страница показывает его адрес вместе с портом, и гость набирает адрес так же: `192.168.0.10:47831` |
| `delay` | `2` | задержка ввода в кадрах, `1` … `12`; у всех игроков действует значение хоста |
| `transport` | `auto` | чем соединяться со страницы СЕТЕВАЯ ИГРА: `auto` — через Steam, если он запущен, и по адресу; `steam` — только Steam; `enet` — только по адресу |
| `lobby` | `friends` | кто видит игру, созданную через Steam: `friends` — друзья, `public` — все, у кого стоит мод |
| `connect` | — | адрес хоста, с которого начинается строка АДРЕС на странице СЕТЕВАЯ ИГРА (без него там стоит `192.168.0.`): чтобы не набирать адрес каждый раз |

### `[log]`

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `level` | `info` | насколько подробно пишется `meleenet.log`: `error`, `warn`, `info`, `debug` |

Есть ещё раздел `[debug]` — для тестовой лаборатории (окна за пределами экрана, нажатия по сценарию,
потери пакетов и так далее). Он описан в исходниках, в `src/mod/config.h`, и для игры не нужен никогда.

## Если игра лежит в защищённой папке

Когда игра стоит в папке, куда обычной программе писать нельзя (например, в Program Files), Windows может
хранить файлы, которые игра меняет, не в ней, а в `%LOCALAPPDATA%\VirtualStore`, и показывать игре эти
копии. Лаунчер это учитывает: он читает и меняет тот `meleenet.ini` и тот `tmntwire.hks`, которые видит
игра. Если записать настройку не удалось, он пишет об этом в нижней строке окна.

Прежде чем лаунчер в первый раз за запуск изменит один из этих файлов, он кладёт копию того, что было, в
`%LOCALAPPDATA%\meleenet\cache` (`meleenet.ini.before-launcher`, `tmntwire.hks.before-launcher`).
