# meleenet — документация

**Русский** · [English](en/README.md)

meleenet — мод для сетевой игры в *TMNT Mutant Melee* (ПК): до четырёх игроков, у каждого своя копия игры.
Он сделан для русского издания игры. Коротко о моде рассказано на [главной странице](../README.md), а
подробно — на этих страницах.
